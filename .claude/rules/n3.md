# Dữ liệu N3 (sách "Ｎ３準備ー文字語彙" + Kanji N3)

## Nguồn & quy trình

```
sources/_archives/*.zip ──extract-zip --level N3──▶ sources/books/N3/{TỪ VỰNG,KANJI}/*.pdf (gitignored)
   score-pdf --only N3 → extract-pdf --only N3   (markdown chỉ để tham khảo — thứ tự đọc bị xáo trộn)
   parse-n3   → sources/_extracted/books/N3/_parsed/{vocab,kanji}.json   (gitignored: có câu ví dụ nguyên văn)
   build      → data/vocabulary/n3/lesson-XX.json + gộp Kanji N3 vào data/kanji/kanji.json
```

- Sách dạng **thẻ**: parser đọc **tọa độ/cỡ chữ** (`extract/layout.py`, xem bằng `layout-dump "<tên>" --page N`, ≤3 trang/lượt), không đọc markdown.
- Từ vựng: số thứ tự (đậm, x<110) mở thẻ; từ chính = nhóm chữ **to nhất** cột trái (22 / 19.7 / 18 / 16); furigana ngay trên từng chữ Hán (gán theo vị trí ký tự → đúng cả 思い出, 申し込む); trợ từ cỡ ~18 bên trái hoặc dính đầu (が/を変わる); nhãn (自)(他); nghĩa đậm x≥270; `・` mở mục ví dụ/ghi chú, `対：` = trái nghĩa.
- Thẻ ghép: số `a – b` → nhiều từ (成功・失敗, が延びる/を延ばす); 1 số + `/` → cách viết khác (`variants`: 降りる/下りる); 1 số + xuống dòng không dấu ngăn → nối (間に合わせる).
- Cách đọc đối chiếu **JMdict** (`check_with_jmdict`): sai → cờ `jmdict_mismatch`; thiếu mà JMdict có 1 cách đọc duy nhất → điền (`reading_from_jmdict`).
- Kanji: số (đậm ~13), chữ (đậm ≥15), Hán-Việt (in hoa đậm), `音：`/`訓：` (Kun nối dòng `・ばす` → `の.ばす`), ví dụ x≥240. Không bắt được chữ → suy từ ví dụ (`char_inferred`); ví dụ không chứa chữ → loại (mảnh vỡ).
- Kanji — **thứ tự chuẩn = bảng tổng hợp trang 1** (chữ cỡ ≥40) → `order` → `n3_lessons: [{lesson, order}]` trong `kanji.json` (kanji v8; mọi bài có chữ, web nhóm + xếp theo trường này; `n3_lesson` = bài đầu). Số trên thẻ có khi in lặp/sai: thẻ không khớp bảng hoặc trùng chữ = nửa sau của thẻ trước → gộp (`merged_split_card`: bài 15 逆, 19 腹, 25 頭, 29 部); thẻ rỗng → bỏ; chữ trong bảng thiếu thẻ → `card_missing`. `parse-n3` in các bài lệch. Chữ dạy ở 2 bài (個: bài 1 và 21) → hiện ở cả 2 bài (Hán-Việt lấy thẻ bài đầu). Tổng 302 lượt / 301 chữ.

## Luật

- ID từ vựng N3: **`n3-NNN`** = số thứ tự sách (001–687, liên tục qua 14 bài) — cố định. `book: "n3"`, bài lưu ở `lesson`.
- **Không đưa câu ví dụ của sách lên `data/`** (bản quyền) — câu ví dụ N3 do AI viết riêng (`enrichment/n3/_examples/`, ai-draft). Từ trái nghĩa / từ liên quan (cụm ngắn) được giữ.
- Từ loại: sách không ghi → suy từ JMdict (`provenance.pos = jmdict`); không khớp → đoán theo hình thức (`ai-draft`).
- Âm Hán-Việt từ vựng N3: ghép âm từng chữ (`derived`) — ưu tiên âm học từ từ vựng **Minna**, sau đó âm sách Kanji N3. Âm sách N3 đi qua `normalize_han_viet` (dấu kiểu cũ HOÀ/TOẠ/THUỶ → HÒA/TỌA/THỦY; KÍ → KÝ).
- Sửa lỗi (commit): `enrichment/n3/vocab-fixes.txt` (`NNN|field|giá trị|ghi chú`, field ∈ word/reading/meaning/pos/particle/drop) và `enrichment/n3/kanji-fixes.txt` (`字|ÂM|ghi chú`, `-` = không có âm). Dòng đầu `# by: ai|user`.
- Kanji N3 gộp vào `kanji.json` (một mục/chữ): `n3_lesson`, `first_lesson` (Minna) có thể null, `han_viet_source: "n3book"`.

## Lệnh

```bash
python -I -X utf8 -m jp_pipeline inspect-zip [--files N]     # liệt kê zip (không giải nén)
python -I -X utf8 -m jp_pipeline extract-zip --level N3      # giải nén an toàn → books/N3/, zip → _archives/
python -I -X utf8 -m jp_pipeline layout-dump "TV Bài 4.pdf" --page 3
python -I -X utf8 -m jp_pipeline parse-n3                    # → _parsed/vocab.json, kanji.json
```

## Câu ví dụ N3 (AI viết, không dùng câu của sách)

```
n3-examples-pack N → AI viết enrichment/n3/_examples/lesson-NN.txt (# by: ai, NNN|ruby|dịch)
  → python -I -X utf8 scripts/kanjify_examples.py <file>   (tự đổi kana → {漢字|かな}: きれい, よく, すぐ, おいしい…)
  → build → check-n3-examples --lesson N                    (lỗi E phải về 0)
```

- Từ đã biết khi kiểm tra = toàn bộ Minna (N5–N4) + N3 bài 1…N.
- Bộ kiểm tra chưa chia được: cụm từ (データを集める), động từ する viết kana (ほっとする), mẫu `～なる`, và vài động từ Sudachi đưa về dạng gốc khác (信じる→信ずる, 通じる→通ずる, 済ませる→済ます) → viết câu với **thể từ điển**.
- Từ N3 có `～` (やっと～た, 決して～ない): `[[…]]` bao cả mẫu, phần giữa tự do.

## Âm Hán-Việt & nghĩa Kanji bổ sung

- `enrichment/kanji/hanviet/NN-*.txt` (`字|ÂM`, `-` = không có âm, dòng đầu `# by: ai|user`): âm cho chữ chưa có nguồn **và** sửa âm sai từ Unihan / sách (浅 THIỂN, 延 DIÊN…). Ưu tiên: từ vựng Minna > file này > sách Kanji N3 > Unihan.
- Âm Hán-Việt từ N3: `derived` nếu mọi chữ từ nguồn tin cậy (Minna / sách N3 / user), `mixed` nếu có chữ từ AI nháp hoặc Unihan → cần soát.
- Nghĩa trích từ thẻ được làm sạch tự động (`clean_meaning`: tiền tố `～ `, `/ `, `A B ( ～`, số thứ tự, mảnh vụn); nghĩa lẫn sang thẻ khác sửa bằng `vocab-fixes` (field `meaning`).
- `same_word` nối 2 chiều Minna ↔ N3 theo mặt chữ (`cross_link_books`).
